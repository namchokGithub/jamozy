# Jamozy v0.4.0

> Pre-release — ยังไม่พร้อมสำหรับ production

## ไฮไลต์

- หน้า Home แบบใหม่: จัดบทเรียนเป็น progress cards และ unit tabs เพื่อดูความคืบหน้าและเลือกเรียนต่อได้ง่ายขึ้น
- Course map ใช้ layout เดียวกับ Home มากขึ้น พร้อมปรับขนาด lesson cards และการตัดบรรทัดให้เนื้อหาอ่านง่าย
- ประสบการณ์พิมพ์มีเสียงแป้นพิมพ์ที่เปิด ปิด และปรับใช้ได้ในทุกโหมดฝึก
- คืนการรับ input จากปุ่ม Space และปุ่ม Space บน Virtual Keyboard พร้อมรองรับสระประสมแบบกดเป็นตัวเดี่ยว
- ปรับขนาดตัวอักษรของตัวบอก Shift และ Jamo บนมือถือให้อ่านได้ชัดขึ้น
- Admin จัดการบทเรียนได้เร็วขึ้นด้วย Save All, การนำเข้า lessons แบบ XLSX และการนำเข้า exercises จาก reviewed CSV
- การนำเข้า XLSX ทนทานขึ้น โดยละเว้นคอลัมน์ว่างท้ายตาราง

## เอกสารและการติดตามงาน

- ปรับ README และ Progress Tracker ให้สะท้อนความสามารถใหม่ของ player, สถิติ Jamo และเสียงแป้นพิมพ์
- เพิ่ม Open work index เพื่อรวมงานที่ยังเหลือและติดตามสถานะได้ง่ายขึ้น

## สิ่งที่ยังเหลือ

- ตรวจรับการใช้งาน Home lessons, keyboard sounds และการนำเข้าข้อมูลจากไฟล์จริงก่อน deploy
- ฟีเจอร์หลัง MVP เช่น Practice, Daily Quest, History และ dark mode
