# Jamozy v0.3.0

> Pre-release — ยังไม่พร้อมสำหรับ production

## ไฮไลต์

- ประสบการณ์พิมพ์ที่ชัดเจนขึ้น: เพิ่ม Virtual Keyboard พร้อมคำแนะนำตำแหน่งนิ้ว และแอนิเมชันสำหรับปุ่มที่กำลังกด กดถูก และกดผิด
- แป้นพิมพ์ตอบสนองครบขึ้น: แสดงผลเมื่อกด Shift และปุ่มจริงบนคีย์บอร์ด ปรับสี focus และไฮไลต์ปุ่มถัดไป โดยคงตำแหน่งแป้นพิมพ์ให้เสถียรระหว่างพิมพ์
- หน้า Home บนมือถือกระชับและใช้งานง่ายขึ้น: ปรับ layout ของ player, ใช้แป้นพิมพ์ทรงโทรศัพท์และเป้าหมายการพิมพ์ขนาดกะทัดรัด พร้อม preload เนื้อหาและปรับปรุงการโหลด Jamo
- แก้ไขการเลือก guest ระหว่าง Firebase authentication และเพิ่มการแจ้งเตือนเมื่อเรียนจบบท
- Lesson และ Review รองรับมือถือดีขึ้น: เพิ่มการนำทางหน้า, สถิติแบบสด, result cards และบันทึก progress สำหรับการ retry
- อ่านเนื้อหาบทเรียนได้ชัดขึ้น: ปรับป้ายประเภท Lesson และข้อความกรณีไม่มีความหมาย
- หน้า Profile ใหม่: เพิ่มแถบ EXP, stat cards และการนำทางที่ใช้งานง่ายขึ้น
- หน้า Settings ใหม่: จัดกลุ่มการตั้งค่าด้วยเส้นแบ่งและ switches พร้อมตัวเลือกความทึบของคีย์บอร์ด โดยคีย์บอร์ดระหว่างพิมพ์ยังแสดงผลชัดเจนเต็มที่
- ปรับ UI โดยรวม: เพิ่ม footer สำหรับหน้าสาธารณะและแก้ตำแหน่ง footer, ป้องกันการเลือกข้อความโดยไม่ตั้งใจระหว่างพิมพ์ และซ่อนฟีเจอร์ Learning Part ชั่วคราว

## หมายเหตุสำหรับการ deploy

- ไม่มีการเปลี่ยนแปลงขั้นตอน build หรือการตั้งค่า environment จาก release นี้
- ควรตรวจรับการทำงานของ Virtual Keyboard, Shift feedback และ layout บนมือถือใน Preview ก่อน deploy

## การทดสอบและเอกสาร

- อัปเดต UI tests ให้ครอบคลุมการเปลี่ยนแปลงของ course map และ Virtual Keyboard
- อัปเดตแนวทางการตรวจสอบ build

## สิ่งที่ยังเหลือ

- ตรวจรับประสบการณ์พิมพ์บนอุปกรณ์จริง โดยเฉพาะ feedback ของแป้นพิมพ์และ layout บนมือถือ
- ฟีเจอร์หลัง MVP เช่น Practice, Daily Quest, History และ dark mode
