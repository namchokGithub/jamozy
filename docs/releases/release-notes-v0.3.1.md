# Jamozy v0.3.1

> Pre-release — ยังไม่พร้อมสำหรับ production

## ไฮไลต์

- ติดตามสถิติการเรียนของผู้เล่นจากทุก session แล้ว ทั้งวันและเดือน เช่น วันใช้งานต่อเนื่อง, perfect streak, เวลาเรียน, จำนวนตัวอักษร และสถิติสูงสุดส่วนตัว
- เพิ่มสถิติความแม่นยำรายปุ่ม Jamo โดยผลล่าสุดมีน้ำหนักมากขึ้น จึงสะท้อนพัฒนาการปัจจุบันได้ดีขึ้น
- หน้า Profile แสดงค่าเริ่มต้นเป็นศูนย์ได้อย่างปลอดภัยสำหรับโปรไฟล์เดิมที่ยังไม่มีข้อมูลสถิติ
- หน้า Review แสดงความแม่นยำของ Jamo แต่ละปุ่ม และมีทางลัดไปยังการฝึก Jamo ที่ยังอ่อน
- เพิ่มโหมด Weak Jamo Practice: ฝึก Jamo ที่พิมพ์พลาดบ่อยจากสถิติของผู้เล่น โดยไม่กระทบ EXP, progress ของบทเรียน หรือรายการทบทวน
- ปรับปรุงการจัดวางหน้า Review และ Weak Jamo รวมถึงปุ่มย้อนกลับจากผลการทบทวน เพื่อให้ใช้งานต่อเนื่องได้ชัดเจนขึ้น
- เพิ่มเสียงตอบสนองขณะพิมพ์ เพื่อให้การฝึกพิมพ์มี feedback ทันที

## หมายเหตุสำหรับการ deploy

- Deploy Firestore Rules ชุดนี้ก่อนหรือพร้อมกับแอป เพื่อให้บัญชีผู้ใช้สามารถอ่านและบันทึก `dailyStats`, `monthlyStats` และ `learnerStats` ของตนเองได้:

  ```bash
  firebase deploy --only firestore:rules
  ```

- ไม่ต้อง backfill ข้อมูลเดิม: โปรไฟล์และสถิติ Jamo รุ่นก่อนยังอ่านได้ตามปกติ และจะเริ่มสะสมข้อมูลใหม่เมื่อผู้เล่นส่งผลการฝึกครั้งถัดไป

## สิ่งที่ยังเหลือ

- ตรวจรับเสียงขณะพิมพ์และประสบการณ์ Review / Weak Jamo บนอุปกรณ์จริงก่อน deploy production
- ฟีเจอร์หลัง MVP เช่น dark mode, หน้าผลลัพธ์ Lesson แบบเฉพาะ และประวัติการเรียนแบบเต็มรูปแบบ
