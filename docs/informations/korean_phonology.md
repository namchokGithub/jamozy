# Korean phonology

    ภาษาเกาหลีใช้ระบบการเขียนที่เรียกว่า ฮันกึล (Hangul / 한글) ซึ่งถูกสร้างขึ้นในศตวรรษที่ 15 ในรัชสมัยของ พระเจ้าเซจงมหาราช เพื่อให้ประชาชนสามารถเรียนรู้การอ่านและการเขียนได้ง่ายขึ้น ก่อนการใช้ฮันกึล ภาษาเกาหลีได้รับอิทธิพลจากอักษรจีนและมีการใช้อักษรที่เรียกว่า ฮันจา (Hanja / 한자) ซึ่งมีลักษณะคล้ายกับการใช้อักษรคันจิในภาษาญี่ปุ่น และมีความซับซ้อนในการเรียนรู้และการเขียนมากกว่า

    อักษรฮันกึลประกอบด้วย พยัญชนะพื้นฐาน 14 ตัว และ พยัญชนะคู่ (เสียงตึง) 5 ตัว ส่วนสระประกอบด้วย สระพื้นฐาน 10 ตัว ซึ่งสามารถนำมาผสมกันเพื่อสร้างสระและพยางค์รูปแบบต่าง ๆ ได้ ลักษณะเด่นของฮันกึลคือการนำตัวอักษรมาจัดเรียงรวมกันเป็น บล็อกพยางค์ โดยแต่ละบล็อกจะประกอบด้วยพยัญชนะและสระ และอาจมีพยัญชนะท้ายร่วมด้วย ตัวอักษรทั้งหมดในหนึ่งบล็อกจะออกเสียงรวมกันเป็นหนึ่งพยางค์

    ด้วยโครงสร้างที่เป็นระบบและมีรูปแบบชัดเจน ฮันกึลจึงเป็นระบบการเขียนที่สามารถเรียนรู้พื้นฐานได้ค่อนข้างรวดเร็ว และช่วยให้ผู้เรียนสามารถต่อยอดไปสู่การอ่านคำศัพท์และประโยคภาษาเกาหลีได้ง่ายขึ้น

## อักษรฮันกึล (한글)

    เป็นระบบการเขียนที่ใช้ในภาษาเกาหลี ถูกประดิษฐ์ขึ้นในปี ค.ศ. 1443 โดยพระเจ้าเซจงมหาราช เพื่อให้ประชาชนสามารถเรียนรู้และใช้งานได้ง่ายขึ้น อักษรฮันกึลมีตัวอักษรที่เรียกว่า จาโม (자모  字母) หรือ อักษรแม่ ทั้งหมด 24 ตัว ประกอบด้วย

## โครงสร้างพยางค์

    ฮันกึลจัดจาโมรวมเป็นบล็อก โดยหนึ่งบล็อกแทนหนึ่งพยางค์เสมอ บล็อกหนึ่งมีพยัญชนะต้นและสระ และอาจมีตัวสะกด (받침) ได้

| โครงสร้าง | ตัวอย่าง | การประกอบ    |
| --------- | -------- | ------------ |
| CV        | 가       | ㄱ + ㅏ      |
| CVC       | 간       | ㄱ + ㅏ + ㄴ |
| CVCC      | 앉       | ㅇ + ㅏ + ㄵ |

    ในตัวอย่าง `앉` พยัญชนะต้น ㅇ ไม่ออกเสียง และ ㄵ เป็นตัวสะกดคู่ จึงนับเป็นโครงสร้าง CVCC

## 받침 (ตัวสะกด)

    받침 คือพยัญชนะที่อยู่ด้านล่างของบล็อกพยางค์ เมื่อออกเสียงท้ายพยางค์ พยัญชนะที่เขียนต่างกันจำนวนมากจะรวมเป็นเสียงตัวสะกดพื้นฐาน 7 กลุ่ม เสียงปิดท้ายเหล่านี้ไม่ปล่อยลมแรงเหมือนพยัญชนะต้น

| กลุ่มเสียงท้าย | 받침 ที่เขียนได้           | ตัวอย่าง   |
| -------------- | -------------------------- | ---------- |
| ㄱ [k̚]         | ㄱ, ㄲ, ㅋ, ㄳ, ㄺ         | 밖         |
| ㄴ [n]         | ㄴ, ㄵ, ㄶ                 | 산         |
| ㄷ [t̚]         | ㄷ, ㅅ, ㅆ, ㅈ, ㅊ, ㅌ, ㅎ | 옷, 맛, 몇 |
| ㄹ [l]         | ㄹ, ㄼ, ㄽ, ㄾ, ㅀ         | 달         |
| ㅁ [m]         | ㅁ, ㄻ                     | 밤         |
| ㅂ [p̚]         | ㅂ, ㅍ, ㄿ, ㅄ             | 밥         |
| ㅇ [ŋ]         | ㅇ                         | 공         |

    เช่น `옷`, `맛`, และ `몇` ลงท้ายด้วยตัวอักษรต่างกัน แต่เมื่อเป็นตัวสะกดเดี่ยวจะอยู่ในกลุ่มเสียง ㄷ [t̚] ส่วน `공` ลงท้ายด้วย ㅇ [ŋ] คล้ายเสียง ง ในภาษาไทย ตัวสะกดคู่บางตัวอาจออกเสียงต่างไปเมื่อเชื่อมกับพยางค์ถัดไป จึงค่อยเรียนกฎเพิ่มเติมในขั้นต่อไป

> ตารางนี้แสดงเสียงเมื่ออยู่ท้ายพยางค์แบบพื้นฐาน ก่อนนำกฎการเชื่อมเสียงหรือการเปลี่ยนเสียงอื่นมาพิจารณา
