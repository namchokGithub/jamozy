# Completion Log

Chronological record of meaningful completed work, one file per month.
Newest entries are at the bottom of the current month's file.

| Month   | File                                  |
| ------- | ------------------------------------- |
| 2026-09 | [docs/log/2026-09.md](log/2026-09.md) |
| 2026-10 | [docs/log/2026-10.md](log/2026-10.md) |

## Adding an entry

- Append to the current month's file (`docs/log/YYYY-MM.md`); create it with
  the same header when a new month starts and add it to the table above.
- Append only. Do not read or edit earlier months to add an entry.
- Keep an entry to 3–5 bullets: what shipped, the commit, and links to the
  plan, spec, or DEC that hold the details. Do not repeat those details here.

```markdown
### YYYY-MM-DD — <unit of work>

- <what shipped, one line each>
- Commit: `<hash>`. Details: <plan/spec/DEC link>.
```
